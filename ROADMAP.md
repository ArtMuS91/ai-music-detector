# Roadmap

Informal backlog for this solo pet project. Not a commitment or schedule — just a place to keep track of what's next.

The MVP is done: a YouTube/YouTube Music link goes through acquisition, preprocessing, detection signals, aggregation and an AI-written explanation to a verdict with confidence in the web UI. Its phase-by-phase plan lives in git history.

## Future

- **Spotify integration** — accept Spotify track links alongside YouTube ones.
- **Audio file upload** — let the user upload an audio file directly instead of pasting a link.
